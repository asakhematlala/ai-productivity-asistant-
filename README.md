# AI-Productivity-Assistant

## Live Demo
https://swift-assistant-bot.lovable.app

## Problem I Solved
Small businesses in Cape Town spend 3-4 hours per week on admin emails and meeting notes. This AI assistant automates that.

## What It Does
- **Email Generator**: Creates professional emails with different tones
- **Meeting Notes Summarizer**: Turns long notes into key points + action items
- **Task Planner**: Creates structured daily plans

## How I Built It
- **ChatGPT**: Used Task + Context + Format to write the prompt
- **Lovable AI**: Built the app using Gemini 2.5 Flash
- **Responsible AI**: Added a disclaimer so users know to verify AI outputs
- 
## Sample Prompt I used 
"Task:Write a proffessional follow-up email to a client after a meeting . Context: The client is a small business owner in cape town . Format: 3-4 sentences , friendly but proffessional tone."
